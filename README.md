修改文章或推荐后，在仓库根目录执行：

```bash
node 工程/scripts/build_articles.mjs
python3 工程/scripts/build_site.py
```

本地预览：

```bash
python3 -m http.server 8788 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8788/`，或直接打开 `index.html`。首页内可切换深色与混合配色；推荐按质量与读者覆盖选择。构造案例、公开资料、作者实测和推演分别标明，创作、复核与发布状态分别记录。
