## 两种阅读方式

图解讲解先说明情境、价值、机制与取舍；完整深入版保留完整推理、来源和边界。新增文章在同一个 HTML 中内置深入全文，支持精确定位和离线阅读。构造案例、作者实测、公开资料与未来推演分别标明。

## 内容与维护

| 位置 | 用途 |
|---|---|
| `原文/` | 每篇文章的 Markdown 正本 |
| `阅读/` | 可独立打开的讲解页、完整深入视图与配图 |
| `posts.json` | 全部文章的分类、摘要和路径 |
| `featured.json` | 当前推荐，第一篇为主推 |
| `project.json` | 文档配对、版本与交付约定 |
| `assets/` | 首页与阅读页的本地样式、脚本和封面 |
| `scripts/` | 从正本与图解稿生成静态页面的工具 |

修改推荐与文章登记后运行：

```bash
python3 scripts/build_site.py
```

修改新增文章的正本或图解稿后运行：

```bash
node scripts/build_articles.mjs
python3 scripts/build_site.py
```

Markdown 渲染器随构建脚本本地提供，许可证位于 `scripts/vendor/MARKED-LICENSE.md`；成品不需要浏览器联网加载解析器或字体。HTTP 访问会读取最新 JSON，直接打开文件则使用最近一次生成的静态快照。

## 推荐规则

首页和 README 的推荐不是“最新五篇”队列。新增文章先作为候选；入选要看质量、读者任务覆盖、理解门槛、证据强度和组合互补性。连续同类主题不应占满入口。推荐摘要写“读者能带走什么”，不夸大证据强度。

## 本地预览

```bash
python3 -m http.server 8788 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8788/`。GitHub Pages 从仓库根目录的 `index.html` 进入。过程检查记录仅在本地保留，不进入文章导航或 Git 跟踪。
