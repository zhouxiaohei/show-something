# show-something

五篇关于 AI 时代工程实践的深度文章，每篇都有两个读物层：**一份经得起逐段拷问的深入版（md）**，和**一份 10 分钟读懂的讲解版（html，带图）**。

选题集中在编码 Agent 真正会咬人的地方：需求如何变成可验证契约、为什么"看起来正确"变廉价了、提示词与代码的边界在哪、"越聊越浅"的机制是什么、以及 Claude Code 与 Codex 的协作可靠性实证。

## 关于这套写法

这五篇不是一次写成的稿子。它们先经过逐篇拷问（正确性 / 是否说清楚 / 条理与通俗度），把"立论前提裸奔、表格代替论证、虚构案例冒充普遍现象、全文无图"这类问题逐条定位并修掉，再由**与写作完全分离的独立视角**按固定维度评分（md 五维、html 四维，锚点示例统一打分尺度），过线才发布。

**知道自己哪里写得不行，是这套流程能起作用的前提**。对应的诊断与核验记录由作者本地留存，不随本仓库发布。
